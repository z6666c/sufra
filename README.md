# سُفرة

منصة للمطاعم والمقاهي: منيو رقمي برمز QR، ومنيو مطبوع A4، وبطاقة طاولة A6، ومنشورات سوشيال، بهوية بصرية واحدة. التعديل في مكان واحد ينعكس على كل المخرجات.

مشروع مستقل عن BrandForge AI، ويعيد استخدام محرك الهوية نفسه (الألوان والرموز والأنماط و QR وتصدير PDF).

## التشغيل

```bash
npm install
cp .env.example .env.local   # كل المتغيرات اختيارية
npm run dev
```

افتح http://localhost:3000

## الميزات

- **قوالب جاهزة** لستة أنشطة (مقهى، مطعم شعبي، برجر، مخبز وحلويات، عصائر، مأكولات بحرية) بأسعار وسعرات تقديرية.
- **محرر المنيو:** أقسام وأصناف، عربي وإنجليزي، سعر، سعرات، وسوم (جديد، الأكثر طلباً، حار…)، مسببات الحساسية السبعة، توفر الصنف، صورة.
- **الهوية:** 3 رموز مولّدة أو رفع شعار المنشأة، ولوحة ألوان قابلة للتعديل.
- **المنيو الرقمي:** صفحة جوال ثنائية اللغة بثلاثة أشكال (أنيق، عصري، بطاقات) تُنشر على `/m/<slug>`.
- **المطبوعات:** منيو A4 بعمودين وتوزيع تلقائي على الصفحات، وبطاقة طاولة A6، بدقة 300 DPI مع القص وعلامات القص.
- **السوشيال:** طبق مميز، جديد في المنيو، عرض خاص، أوقات العمل، ستوري.
- **الحزمة الكاملة ZIP.**
- **اشتراطات هيئة الغذاء والدواء:** السعرات بجانب كل صنف وعبارة الاحتياج اليومي، ومسببات الحساسية.

## النشر والتخزين

- خادم خاص: يحفظ المنيو المنشور كملفات JSON في `MENU_STORAGE_DIR` (افتراضياً `.data/menus`).
- Vercel أو استضافة بلا قرص دائم: اضبط `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN`.
- عند النشر أول مرة يُنشأ مفتاح تعديل يُحفظ في متصفح صاحب المنيو، ويُطلب لأي تحديث لاحق.
- اضبط `PUBLIC_BASE_URL` ليكون رابط QR على دومينك.

## ملاحظات

- السعرات في القوالب تقديرية؛ يجب أن يتحقق منها صاحب المنشأة.
- الصور تُضغط في المتصفح (640px) قبل الحفظ لإبقاء المنيو المنشور صغيراً (الحد 900 KB).

## محرك الشعارات v2
- يقرأ الاسم (يتجاوز «ال» والكلمات العامة مثل شركة/مطعم/مقهى) ونوع النشاط، ويختار رموزاً خاصة بالقطاع (`lib/logo/motifs.ts`).
- **المُركِّب** (`lib/logo/composer.ts`): يبني كل شعار لحظة الطلب من محاور مستقلة: النواة (حرف، حرفان، رمز نشاط) × 18 إطاراً × 5 معالجات × 4 حلي × 8 لمسات × 3 أنظمة ألوان × مقياسان. هذا يعطي أكثر من 120 ألف تركيبة لكل علامة، و1.5 مليون تقريباً إجمالاً. `compositionSpace()` تحسب العدد الفعلي لكل علامة.
- منع التكرار: كل تصميم له مفتاح تركيبي (`signature`)، وما عُرض سابقاً لا يُعاد.
- السرعة: دفعة من 6 مفاهيم في أقل من 1 مللي ثانية تقريباً، داخل المتصفح بلا خادم.

## تجربة الذكاء الاصطناعي (تجريبي)
`lib/ai-trial.ts` يولّد أفكار شعارات كصور عبر Pollinations.ai، وهي خدمة مجانية بلا مفتاح، للاستلهام فقط. الصور نقطية وقد تحتوي أخطاء في الحروف. للإنتاج استبدلها بـ Recraft (SVG متجهي) عبر مسار خادم.

## الحسابات: إدارة + ديمو
| الحساب | الدخول الافتراضي (تطوير) | الصلاحيات |
|---|---|---|
| إدارة | `admin` / `admin123` | كل شيء + لوحة `/admin` (المنيوهات المنشورة وحذفها، حالة الإعدادات) |
| ديمو | `demo` / `demo1234` | كل المحرر والتصدير، **بدون** نشر المنيو أو Gemini/Recraft |

- **الوضع الافتراضي عام:** أي زائر يفتح التطبيق مباشرة كحساب ديمو بدون تسجيل دخول، ولوحة الإدارة على `/login`. لجعل التطبيق يتطلب الدخول: `PUBLIC_DEMO=false`.
- الحماية في `proxy.ts` (Next.js 16)، ما عدا المنيو المنشور للزبائن `/m/...` فهو عام.
- الجلسة كعكة HttpOnly موقّعة HMAC-SHA256 لمدة أسبوع، وفيه حد لمحاولات الدخول (10 كل 10 دقائق لكل IP).
- **في الإنتاج:** اضبط `AUTH_SECRET` و `ADMIN_PASSWORD` إجبارياً. بدونهما يتعطل حساب الإدارة وكلمة المرور الافتراضية `admin123` ما تشتغل. بيانات الديمو تُغيَّر أو يُعطَّل الحساب عبر `DEMO_ENABLED=false`.
